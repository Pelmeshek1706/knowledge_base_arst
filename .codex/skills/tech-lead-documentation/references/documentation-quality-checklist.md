# Documentation Quality Checklist

- Factual and consistent with code/docs.
- No invented features.
- MVP scope separated from future work.
- Agentic workflow includes user approval gate.
- Python Engineer one-task-at-a-time rule is explicit.
- QA one-task-at-a-time rule is explicit.
- Setup commands are executable or TODO-marked.
- Architecture summary matches current docs.
- Deep docs are linked instead of duplicated excessively.
