# Research Policy

Use web research only when needed.

Research is required when:

- external API/library behavior may have changed;
- model names/capabilities are version-sensitive;
- dependency choice affects architecture;
- LangChain, LangGraph, Neo4j, MCP, Codex, or OpenAI API details are involved;
- user explicitly asks to research current sources.

Preferred sources:

1. Official documentation.
2. Official GitHub repositories.
3. Release notes/changelogs.
4. Standards/specifications.
5. Reputable engineering blogs only if official docs are insufficient.

Research output must separate:

- facts;
- source/version/date;
- implication for personal_kb;
- recommendation.
