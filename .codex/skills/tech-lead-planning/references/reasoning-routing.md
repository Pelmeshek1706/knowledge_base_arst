# Reasoning Routing

## Medium Reasoning

Use for:

- normal developer questions;
- routine planning;
- local issue triage;
- clarifying implementation scope;
- small non-architectural decisions.

Agent:

- `ai_ml_tech_lead`

## High Reasoning

Use for:

- architecture decisions;
- cross-module design;
- GraphRAG strategy;
- retrieval/QA strategy;
- model/tooling decisions;
- version-sensitive research;
- ADR-level decisions;
- unresolved blockers.

Agent:

- `ai_ml_tech_lead_architect`

## Approval Gate Applies to Both

Neither Tech Lead agent may authorize implementation until the user approves the plan.
